## 🧩 About

**The Long Dark Companion** is a curated list of The Long Dark open-source tools:

- **Overlays** — on-screen helpers, layout notes, item tracker, map viewer
- **Quality-of-Life Helpers** — loot catalog, inventory manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Item Tracker — highlight nearby resources and loot
- Map Overlay — display current region map with markers
- Stat Monitor — track condition, stamina, temperature
- Time Scale — adjust in-game time for study (0.1x to 5x)

### Wallhack
- Loot Catalog — browse items, weights, and spawn locations
- Inventory Manager — organize and filter carried items
- Crafting Notes — recipe list and material requirements

### Aimbot
- Waypoint Notes — mark and review key locations
- Wildlife Tracker — log animal spawns and behavior
- Weather Notes — record patterns and plan routes
